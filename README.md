# Product Review Rating Prediction (NLP - BERT)

This project uses Natural Language Processing (NLP) and Transformer models (BERT) to predict product ratings based on user reviews.

## 🔧 Technologies
- Python
- PyTorch
- Transformers (HuggingFace)
- Pandas, NumPy
- NLTK

## 📊 Features
- Text preprocessing (tokenization, stopword removal, stemming)
- Dataset balancing using oversampling
- Fine-tuning DistilBERT for classification
- Model evaluation (Accuracy, MAE, RMSE)

## 📈 Results
- Achieved ~98% accuracy on test data

## 📁 Dataset
Amazon product reviews dataset (~195k reviews)

## 🚀 Future Improvements
- Web application / API
- Multilingual support
